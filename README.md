\## Descripción



Repositorio correspondiente a la segunda actividad de la asignatura de Programación Orientada a Objetos.



En esta actividad se desarrollan diferentes ejercicios utilizando el lenguaje de programación Java, aplicando conceptos relacionados con clases, objetos, atributos, métodos, constructores y parámetros.



\## Ejercicios



1\. \*\*Persona:\*\* creación de objetos que representan personas y sus datos personales.

2\. \*\*Planeta:\*\* representación de planetas, sus características y diferentes métodos para calcular su densidad y determinar si son planetas exteriores.

3\. \*\*Automóvil:\*\* representación del estado y comportamiento de un automóvil.

4\. \*\*Figuras geométricas:\*\* implementación de diferentes figuras y métodos para calcular áreas, perímetros y otras características.

5\. \*\*Cuenta bancaria:\*\* representación de una cuenta bancaria y realización de operaciones como consignaciones, retiros, consulta de saldo y cálculo de intereses.
